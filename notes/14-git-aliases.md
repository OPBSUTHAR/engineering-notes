# Useful Git aliases for everyday work

Small aliases remove friction from the commands you type every day. Keep them few, memorable, and documented in the repository.

## Key practices

- Create a compact graph log for branch and merge history.
- Add an undo alias that performs a soft reset to the previous commit.
- Add a cleanup alias that deletes local branches already merged into main.
- Use a work-in-progress alias for temporary commits that you will squash later.
- Document aliases in the README so new contributors can adopt them.

## Why it matters

Good aliases make the safe path the fast path, which leads to more consistent Git habits.
